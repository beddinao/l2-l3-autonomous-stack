# *`GNS3 Resources`*

This directory contains the essential Cisco virtual machine images and configuration files required to execute the GNS3 network topologies in this repository.

## Contents

* **`vios-adventerprisek9-m.spa.159-3.m6.qcow2`**: The Cisco IOSv Layer 3 router QCOW2 appliance image.
* **`vios_l2-adventerprisek9-m.ssa.high_iron_20200929.qcow2`**: The Cisco IOSv Layer 2 switch QCOW2 appliance image.
* **`IOSv_startup_config.img`**: The baseline startup configuration disk image utilized by the Cisco nodes.
* **`cisco-ios-l2`**: Associated resource or configuration directory for the Cisco Layer 2 instances.
